# Interactive Sales Optimization Dashboard 🧠📊🍕

This project is an Excel-based dashboard built for optimizing product output using constraints like ingredient availability, cost, and profit.

## 🔧 Features
-  Excel Solver optimization
- Dynamic charts and tables
- Automated macro with button click
- Ingredient constraints
- User-friendly input interface
- One-click optimization via VBA

## Use Case
This model simulates optimizing pizza categories based on ingredient limits and profit margins, but it can be adapted for any product mix planning.

## Tools Used
- Microsoft Excel (Solver + VBA)
- Form controls and charts
- Dashboard UX formatting
